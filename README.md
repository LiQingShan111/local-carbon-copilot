# 地方碳策 AI

面向宁波制造业中小企业的产品碳足迹与减排决策助手，也是 AI4Climate 全球青年气候解决方案挑战赛开放选题原型。

## 项目定位

- One Place：中国浙江省宁波市
- One Climate Problem：中小制造企业的碳数据分散，难以形成可信基线和可执行的减排优先级
- One AI Solution：用 AI 完成凭证理解、因子匹配、异常识别和约束排序，由确定性公式引擎负责排放计算

## 本地查看

网站为无构建步骤的静态页面，直接打开 `dist/index.html`，或用任意静态 HTTP 服务托管 `dist` 目录即可。

## 重要说明

当前企业、排放因子、成本和措施参数为演示或匿名合成数据，不构成正式碳足迹认证、政策申报或投资建议。正式结果需依据最新标准和企业授权数据，由专业人员复核。
